## Methodology

UMEQAM does not answer questions — it evaluates AI-generated responses for compliance.

**Pipeline per request:**
1. Pre-risk scan (<10ms)
2. R-ME Meaning Extractor — epistemic signals
3. R-EG Epistemic Guardrail — domain fast path
4. Domain Judge Council — medical/legal/finance/mental
5. LLM Ensemble (GPT-4o + DeepSeek) — ambiguous cases only

**Verdict scale:** PASS / REVIEW / FAIL
